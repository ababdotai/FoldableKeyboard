# Mac 组合键

在设置的“按键布局”中选择 `Mac`。⌘ 对应 Command，⌥ 对应 Option，⌃ 对应 Control；不是将所有 Ctrl 改成 Command。

## 操作方式

- 按住修饰键，再点击字母、数字或方向键；可以同时按住多个修饰键，也可以保持按住后连续点击不同按键。
- 也可依次点击修饰键和主键；单击修饰键只作用于下一键，连续点击两次锁定，再点一次关闭。
- Caps Lock 只影响字母大小写，不会把 ⌘C 变成 ⇧⌘C。旋转、隐藏或取消触摸会清除活动手势。

常用组合包括 ⌘A/C/V/X/Z/S/F、⇧⌘Z、⇧⌘3/4/5、⌥←/→、⌥退格、⌘方向键、⌃空格、⌘空格和 ⌥⌘Esc。实际动作由远端应用和快捷键设置决定。

Mac 模式在本地将 `fn+退格` 转为向前删除，`fn+↑/↓` 转为 PageUp/PageDown，`fn+←/→` 转为 Home/End，保留其他修饰键。这与 [Apple 快捷键定义](https://support.apple.com/en-us/102650) 一致。

## UU 必须配置的兼容入口

Android 会拦截 Meta/Command 以及部分系统组合；单纯向系统发送 Meta 并不等于 UU 收到 Command。UU Mac 悬浮键盘默认启用 Command 兼容选项（右 Ctrl）：仅将 Command 编码为右 Ctrl，交由 UU 内建映射恢复为 Command；真正的 Control 仍为左 Ctrl，两者可同时使用。

在 UU 的“按键替代”中开启 **`「右 Ctrl」=「Cmd」`**，关闭 **`「右 Alt」=「Esc」`**，并关闭 UU 的“全键盘控制”（无障碍服务名“UU远程键盘外设”）。官方 UU 4.40.0 在该无障碍服务开启时不执行右 Ctrl 替代，不能自动假定兼容前提已经满足。FoldableKeyboard 不会代改 UU 的设置。

若关闭兼容开关，将恢复直接 Meta 事件，可能被 Android 消费。这个替代只作用于 UU Mac 悬浮键盘，不改变普通 RAW、Normal 或 Windows 布局。

## 远程快捷操作栏

UU 浮动键盘默认显示可横向滚动的快捷栏：全选、复制、粘贴、撤销、重做、查找、保存。设置中的“显示远程快捷操作栏”可随时关闭；它不影响普通输入法，也不改变方向键布局。折叠浮窗时快捷栏一起隐藏。

| 操作 | Mac 布局 | Win 布局 |
| --- | --- | --- |
| 全选 / 复制 / 粘贴 | ⌘A / ⌘C / ⌘V | Ctrl+A / Ctrl+C / Ctrl+V |
| 撤销 / 重做 | ⌘Z / ⇧⌘Z | Ctrl+Z / Ctrl+Y |
| 查找 / 保存 | ⌘F / ⌘S | Ctrl+F / Ctrl+S |

点击快捷操作会清除键盘残留的修饰键和未完成的触摸手势，再发送该操作自己的组合键。各次点击按原有队列顺序发送，不自动重试；不会因为后一次点击就丢弃前一次操作。复制、粘贴使用远端应用的剪贴板，不读取或传输手机剪贴板内容。

快捷栏沿用相同的 HID 通道和 Command 兼容映射，因此仍需上述 UU 配置与远端焦点。HID 跟随系统焦点，发送前检查不能消除切换应用的竞争窗口；输入时不要切换应用。按钮显示的是通用桌面快捷键，具体应用可能重新定义这些动作。Mac 映射依据 [Apple 快捷键说明](https://support.apple.com/en-us/102650)。提交计数可在浮窗“诊断”中查看；HID 报告提交不等于远端执行成功。

## Magic Keyboard 外观

在主题设置中选择 `Magic Keyboard`（银白）或 `Magic Keyboard (Black)`（黑色）。原浅色与 Dark 主题分别自动升级为对应皮肤，保留原选择；独立的 AMOLED 纯黑主题及自定义主题不变。银白版使用银灰底板、白色键帽，黑色版使用石墨灰底板、黑色键帽和白色刻字。两者共用小圆角、细边缘与固定大写字母刻字，同时应用于普通输入法和 UU 浮窗，快捷栏也沿用主题。

空格不印文字，删除、回车不再使用蓝色块。按下时键帽变灰；修饰键的一次性激活和锁定分别以单点、双点指示，Caps Lock 锁定时亮绿点。字母大写刻字不代表发送大写字符，实际大小写仍由 Shift/Caps Lock 决定。

皮肤不改变键值、组合键或当前 Mac 倒 T 方向键位置；F1–F12 仍发送功能键，不模拟 Apple 媒体键或 Touch ID。

## 支持边界

快捷键目前逐次发送完整的“修饰键按下 → 主键 → 修饰键释放”序列。按住 ⌘ 连按 Tab 不会在远端持续保持应用切换器；fn/Globe 的系统专属功能、媒体键和修饰键配合鼠标点击也不在该实现范围。标准 HID 不提供通用 Fn：仅支持上文已翻译的 fn+方向/删除组合；其他 Fn 组合会明确拒绝，请取消 fn 锁定再输入。

UU 自身会处理真正的 `⌃⌥←/→` 和 `⌃⌥Enter`（切换显示屏、沉浸鼠标），并非全部组合都会透明送到 Mac。若 UU 未消费按键，Android 还可能把 Ctrl(+Shift)+Space、Ctrl+Alt+Z 用于手机键盘切换或无障碍快捷键；不同厂商也可能增加系统快捷键。参见 [AOSP 窗口按键策略](https://raw.githubusercontent.com/aosp-mirror/platform_frameworks_base/android14-release/services/core/java/com/android/server/policy/PhoneWindowManager.java)。

触摸、路由及事件序列自动化测试不等于手机 → UU → Mac 已完成真机验收。使用 UU 时仍须关闭其“输入法”面板，让硬件键盘视图获得焦点；普通 RAW 通道不能修复 UU 输入法入口丢弃字母的问题。
